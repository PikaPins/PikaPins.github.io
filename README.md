# 皮卡丘的资源推荐

这是一个基于GitHub Pages的资源推荐页面，用于展示和分享各类优质资源，包括影视资源、书籍资源、实用工具、AI资源等。页面设计简洁精美，并融入了皮卡丘元素作为视觉亮点。

## 功能特点

- 左侧动态分类导航，右侧资源卡片展示
- 资源信息通过config.json配置，易于更新和维护
- 响应式设计，适配各种设备屏幕
- 精美的皮卡丘主题元素
- 资源卡片点击可在新标签页打开对应网站

## 使用方法

### 本地预览

1. 克隆或下载本仓库到本地
2. 使用浏览器直接打开`index.html`文件即可预览

### 部署到GitHub Pages

1. Fork本仓库到你的GitHub账号
2. 在仓库设置中启用GitHub Pages功
